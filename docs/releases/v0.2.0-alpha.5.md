Steam Deck 전용 설정·동기화 화면과 Steam 바로가기 실행 기능을 추가한 시험판입니다.

- 기존 Windows/PC 화면을 유지하며 **Deck 화면 / 기존 화면**으로 전환할 수 있습니다.
- Deck 화면에서 전체·개별 동기화, 서버 설정, 비밀번호 저장, 설치본 설정·탐색을 사용할 수 있습니다. 상세 게임 등록·이력·백업은 기존 화면으로 연결합니다.
- Steam 설정 화면용 바로가기에 실행 옵션 `deck`을 지정하세요. 매번 새 일회용 인증 링크로 전용 브라우저 창을 열고 창 종료까지 실행 상태를 유지합니다. 토큰 포함 URL을 Steam에 저장할 필요가 없습니다.
- SteamOS에서는 Desktop Mode의 Discover에서 Chromium 또는 Google Chrome을 먼저 설치하세요. 네이티브 또는 Flatpak 설치본을 탐색하며 Windows는 Chrome/Edge를 사용할 수 있습니다.
- 게임용 바로가기는 `launch --deck --launch-profile 프로필ID`를 사용할 수 있습니다. 기존 시작 전·종료 후 동기화를 유지하고 문제 발생 시 새 인증 링크로 Deck 화면을 엽니다.
- 충돌은 버전을 선택한 뒤 적용을 확인하며 기존 해시 재검증을 유지합니다. 방향키·Tab·Enter·Esc 탐색을 지원하고 컨트롤러는 Steam Input 키보드 매핑을 사용합니다.

기존 프로그램 또는 사용자 서비스를 종료하고 Windows x64 ZIP / SteamOS·Linux x64 tar.gz 전체 내용을 새 폴더에 압축 해제하세요. 기존 상태 폴더와 `--data-dir`을 유지하면 설정·동기화 이력을 계속 사용합니다.

Linux에서 자동 테스트, 실제 Chromium 앱 창 열기·닫기, 인증 링크 재발급과 브라우저 UI를 검증했습니다. SteamOS Gaming Mode·Flatpak 브라우저·Windows 앱 창은 실기기 검증이 필요합니다. Steam 강제 중지는 자동 시작한 자식 백엔드에 영향을 줄 수 있으며 상시 실행에는 기존 사용자 서비스 구성을 사용할 수 있습니다.

EmuDeck `ryujinx.sh` 자동 연동과 서비스 설치 편의 기능은 이번 릴리즈에 포함되지 않습니다.
