WebDAV 비밀번호 파일 저장과 게임 정보 일괄 조회를 추가한 시험판입니다.

- 설정 → WebDAV 비밀번호에서 **파일에 평문 저장 (개인 기기용)**을 선택할 수 있습니다. **이 기기의 파일에 평문 저장** 체크 후 **연결 확인 후 적용**을 누르세요.
- OS 보관함 없이 같은 사용자·상태 폴더로 재시작하거나 서비스로 실행하면 비밀번호를 자동으로 불러옵니다. 서버 주소·계정별 분리, 잠금·불러오기·삭제, 저장 방식 전환을 지원합니다.
- 파일은 상태 폴더의 `credentials-plaintext/*.json`에 암호화 없이 저장됩니다. 파일을 읽을 수 있으면 비밀번호를 볼 수 있습니다. Linux 파일 권한은 600, 폴더는 700이며 상태 폴더 백업에도 암호가 포함될 수 있습니다. 사용자가 선택한 경우에만 파일 저장을 사용합니다.
- 내 게임 → **전체 이름·썸네일 가져오기**로 현재 탐색한 게임과 모든 등록된 동기화 대상의 정보를 일괄 조회할 수 있습니다. 언어 선택, 중복 제거, 진행률, 중지, 개별 실패 내역을 제공하며 직접 지정한 이름은 유지합니다.

기존 프로그램 또는 사용자 서비스를 종료하고 Windows x64 ZIP / SteamOS·Linux x64 tar.gz의 전체 내용을 새 폴더에 압축 해제하세요. 기존 상태 폴더와 `--data-dir`을 유지하면 설정·동기화 이력을 계속 사용합니다. 서비스가 이전 실행 파일 경로를 가리킨다면 해당 경로도 갱신하세요.

Linux에서 파일 저장·재시작·WebDAV 인증·잠금·삭제를 실제 API와 브라우저로 검증했습니다. SteamOS 실기기 Gaming Mode·절전 복귀 검증은 별도로 필요합니다.
