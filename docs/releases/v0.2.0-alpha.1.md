Yuzu Account Save와 Ryujinx↔Yuzu 교차 동기화를 추가한 시험판입니다.

## 추가 기능

- 설치본별 데이터/NAND 루트 지정과 게임·사용자·Title ID 자동 탐색.
- Yuzu 관리 파일을 제외한 공통 스냅샷과 적용 시 관리 파일 보존.
- 여러 로컬 설치본을 같은 게임·슬롯에 연결하고 각각의 baseline으로 충돌 처리.
- 교차 세이브의 시험 적용 승인·실제 게임 로드 확인 상태. 출처 빌드·기록한 게임 버전 조합 변경 시 재확인.
- 서버 전용 세이브 복원 예약. 초기화 세이브 자동 업로드 차단 및 백업 후 예약 버전 복원.
- 설치본·그룹별 Steam 실행 프로필, 웹 대시보드 프로필 선택, 종료 후 대기 요청의 원래 대상 범위 유지.
- 이전 v1 설정의 SQLite 백업 및 선택한 원격 revision을 빈 v2 그룹으로 가져오기.

## 업데이트 전 확인

새 기본 상태 폴더는 `RyuSync-v2` / `ryusync-v2`, 새 원격 영역은 `ryusync-v2/<workspace>`입니다. 기존 v1 DB와 서버 이력은 자동으로 변경하지 않습니다. 이전 백엔드와 Steam 바로가기를 종료하고 [Yuzu 설정·가져오기 문서](https://github.com/tugsis/ryujinx-save-sync/blob/main/docs/yuzu.md)를 따라 전환하세요.

Windows용 ZIP 또는 SteamOS/Linux x64용 tar.gz 전체를 압축 해제하세요. 실행 파일 하나만 복사하지 마세요. .NET SDK나 Node.js는 실행에 필요하지 않습니다.

## 검증 및 제한

- 합성 세이브 단위 테스트와 실제 HTTP/WebDAV 통합 테스트, Chrome 설정 화면 조작으로 검증했습니다.
- 실제 게임·에뮬레이터 빌드의 세이브 호환성은 보장하지 않습니다. 별도 백업을 만들고 게임에서 로드·저장·종료를 확인하세요.
- 기본 Account Save 레이아웃만 지원합니다. Device/System Save, 다른 Yuzu 계열 포크 전체 호환성, 프로필 표시명 자동 판독은 지원하지 않습니다.
- 자동 실행은 직접 실행하는 EXE/Linux 바이너리용입니다. AppImage 원본·Flatpak 자동 실행은 제외됩니다. 해당 구성은 에뮬레이터 종료 후 웹에서 수동 동기화할 수 있습니다.
- Google Drive, 영구 자격 증명 저장, 오프라인 실행 선택, 백업 복원·저널 해제 UI는 후속 작업입니다.
