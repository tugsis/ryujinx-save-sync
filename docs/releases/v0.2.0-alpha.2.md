WebDAV 비밀번호 저장, 게임 이름·썸네일 조회와 설정 화면 개선을 포함한 시험판입니다.

- WebDAV 비밀번호를 선택적으로 기기에 저장할 수 있습니다. Windows Credential Manager와 Linux Secret Service를 사용하고, 저장값 재조회·현재 세션 잠금·삭제 및 이전 연결 정리를 지원합니다. Linux 보관함이 없거나 잠겨 있으면 세션 입력을 사용할 수 있습니다.

- Yuzu의 게임 목록 이름 캐시를 읽어 ‘내 게임’에 이름을 표시합니다. 캐시 폴더를 별도 지정할 수 있습니다.
- 게임 이름 직접 수정·자동 이름으로 되돌리기와 이름 출처 표시를 추가했습니다. 기존 연결을 해제하지 않고 표시 이름만 변경할 수 있습니다.
- ‘내 게임 → 이름·썸네일 설정’에서 Nlib API로 이름과 썸네일을 가져올 수 있습니다. 한국어·영어·일본어 선택, 기기 내 캐시, 직접 지정한 이름 보존을 지원합니다. 버튼을 눌렀을 때만 조회하며 인터넷 연결 실패 시 기존 정보를 유지합니다.

- 설치본·저장소 설정에 필수, 선택, Steam 실행 시 필수 표시를 추가했습니다.
- Yuzu 데이터 루트와 커스텀 NAND는 둘 중 하나만 필요하며 입력 상태에 따라 표시가 바뀝니다. 빌드·작업 디렉터리·인수는 선택입니다.
- ‘저장된 설치본 탐색’을 ‘게임 탐색’으로 통일했습니다. 설정을 바꾸면 ‘저장 후 게임 탐색’으로 표시되어 저장과 탐색을 한 번에 실행할 수 있습니다.
- 경로가 비어 있거나 작업 중일 때 버튼 아래에 이유를 표시합니다. 설치본 옆에서 설정만 저장할 수도 있습니다.
- 기본 Ryujinx 탐색에도 같은 저장 후 탐색 흐름을 적용했습니다.

기존 `v0.2.0-alpha.1` 사용자는 백엔드를 종료하고 배포 폴더 전체를 교체하세요. 기존 상태 폴더와 `--data-dir` 설정을 유지하면 됩니다. 새로운 빈 상태 폴더를 만들 필요는 없습니다.

Windows x64 ZIP 또는 SteamOS/Linux x64 tar.gz 전체를 압축 해제하세요. Yuzu 교차 세이브 호환성, AppImage·Flatpak 자동 실행 등 기능 범위는 이전 시험판과 같습니다. 자세한 사용법은 포함된 `docs/yuzu.md`를 참고하세요.

비밀번호 저장은 설정의 **WebDAV 비밀번호 → 이 기기에 안전하게 저장 → 연결 확인 후 적용**으로 사용합니다. Linux에서는 시스템의 `libsecret`과 사용자 Secret Service가 필요합니다. 사용할 수 없는 환경에서는 이번 실행에서만 비밀번호를 입력할 수 있습니다. SteamOS의 Desktop/Gaming Mode 전환·절전 복귀와 실제 Windows 데스크톱 세션 동작은 추가 실기기 검증이 필요합니다.
