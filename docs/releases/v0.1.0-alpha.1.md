RyuSync 첫 시험 배포입니다. Windows 11과 SteamOS/Linux에서 Ryujinx User Save를 WebDAV로 동기화합니다.

## 다운로드 및 실행

- **Windows 11 x64**: `ryusync-v0.1.0-alpha.1-win-x64.zip` 전체를 압축 해제하고 PowerShell에서 `./ryusync.exe serve`를 실행합니다.
- **SteamOS / Linux x64**: `ryusync-v0.1.0-alpha.1-linux-x64.tar.gz`를 빈 폴더에 압축 해제하고 `./ryusync serve`를 실행합니다. 필요하면 `chmod +x ryusync`로 실행 권한을 부여합니다.
- 터미널에 표시되는 설정 링크를 같은 기기의 브라우저로 엽니다. 실행 중인 백엔드의 설정 페이지를 다시 열려면 별도 터미널에서 `./ryusync.exe open` 또는 `./ryusync open`을 실행합니다.
- .NET SDK와 Node.js 설치는 필요 없습니다. 실행 파일 하나만 옮기지 말고 압축파일 전체를 해제하세요. Linux에서는 배포판의 기본 시스템 라이브러리가 필요합니다.
- 파일 무결성 확인용 `SHA256SUMS.txt`를 함께 제공합니다. 상세 설정·Steam 등록·업데이트 절차는 압축파일의 `README.md`를 참고하세요.

## 포함 기능

- 로컬 웹 설정 페이지, Ryujinx 세이브 탐색·등록, WebDAV 연결 테스트와 수동 동기화.
- Steam 실행 래퍼를 통한 게임 시작 전·종료 후 동기화.
- 변경 이력·충돌 선택, 덮어쓰기 전 백업, 중단 작업 복구.
- Windows에서 SQLite 연결 풀 때문에 테스트 정리가 실패하던 문제 수정.
- HTTPS 인증서·TLS, DNS, 서버 접속 오류를 구분하는 안내.

## 현재 제한

- 개발 초기 시험판입니다. 실제 세이브를 별도로 백업하고 기기 사이에서 게임을 번갈아 실행하며 검증하세요. Windows·SteamOS의 실제 Ryujinx 왕복 플레이 전체 검증은 아직 완료하지 않았습니다.
- Google Drive는 지원하지 않습니다. WebDAV만 구현되어 있습니다.
- WebDAV 비밀번호는 기본적으로 메모리에만 유지됩니다. 백엔드 재시작 후 다시 입력하거나 `RYUSYNC_WEBDAV_PASSWORD` 환경변수를 사용하세요.
- Linux 배포물은 x86-64 PC / Steam Deck용입니다. Debian Jessie 기반 WD MyBookLive 등 구형 NAS에서 실행하는 서버 프로그램이 아닙니다. NAS는 WebDAV 저장소 역할을 합니다.
